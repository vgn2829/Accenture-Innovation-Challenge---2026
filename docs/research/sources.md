## Source Quality Policy

This project applies the following source hierarchy:
1. Official documentation (highest trust)
2. Academic papers
3. Official technical blogs (recognized vendors)
4. Recognized standards bodies (OWASP, NIST)
5. Technical community blogs (used with caution)
6. SEO aggregators (used only when no primary source available; always flagged)

**No sources were fabricated in this research.**  
**No assumptions were silently promoted to facts.**
