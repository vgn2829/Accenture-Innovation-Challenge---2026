## Interpretation

These are not real-world accuracy or safety guarantees. The corpus is synthetic and generated from reviewed mechanism templates, so it is useful for regression and policy-behavior verification but not for prevalence, calibration, or generalization claims. The 0% false-release result must not be presented as production performance.

## Cost/latency trade-off

The runner records local wall-clock observations for adaptive and forced-deep execution. Cost is `NOT MEASURED`; no token savings are claimed. Deep verification runs Tier 2 for all cases, while adaptive verification uses policy-selected depth. Local timings are too environment-sensitive to be treated as an SLA.

## Feedback outcomes

Feedback is generated from Control Desk adjudication and persisted in SQLite. The dashboard reports reviewer outcomes and corrections. Feedback does not automatically alter policy.

## Limitations

- No public dataset is included in the measured result.
- No statistical/embedding detector is implemented.
- No calibration curve, Brier score, or ECE is claimed.
- Fairness and PII labels are synthetic mechanism labels.
- Multi-turn cases use controlled tool/session histories, not real agent traces.
